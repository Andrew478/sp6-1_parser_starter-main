# Парсинг веб-страницы

Учебный проект с парсингом веб-страницы от Практикума. В проект встроены тесты для проверки результата.

В проекте отрабатываются навыки поиска содержимого в DOM и его вывод в консоль единым объектом.

Для запуска откройте `index.html`. Вся работа выполняется в файле parser.js.

#### Запуск тестов
По готовности или сразу раскомментируйте вызов makeTests();
